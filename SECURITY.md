# Security Policy

## Supported Versions

We actively monitor and fix security vulnerabilities in the following versions of this project:

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :white_check_mark: |
| 0.x.x   | :x:                |

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

If you believe you have found a security vulnerability in this project, please report it responsibly using one of the following methods:

1. **GitHub Security Advisories (Preferred):** Navigate to the **Security** tab of this repository on GitHub, click **Reporting** -> **Report a vulnerability**, and fill out the private form.

### What to Include in Your Report
To help us handle your report quickly, please include:
* A clear and descriptive subject line.
* The specific component or version affected.
* A detailed technical description of the vulnerability.
* Step-by-step instructions or a Minimal Reproducible Example (MRE) to replicate the issue.
* Potential impact or attack scenarios.

## Our Process

* **Acknowledgment:** A project maintainer will acknowledge receipt of your report within 48 hours.
* **Triage:** We will investigate the issue and keep you updated on our progress.
* **Resolution:** If confirmed, we will coordinate a fix and release a patched version.
* **Disclosure:** We follow a Coordinated Vulnerability Disclosure (CVD) model. We ask that you do not publicly disclose the vulnerability until a patch has been released to protect downstream users.

Thank you for helping keep this project safe for everyone!
