# Changelog - Lightsaber Duel

## [2.0.0] - 2026-06-19

### Added
- **Power-ups System**: Health restore, speed boost, and damage multiplier
- **Tournament Mode**: Best-of-3 series with escalating difficulty
- **Survival Mode**: Face increasingly difficult opponents
- **Practice Mode**: Train against stationary dummies
- **Career Tracker**: Track statistics and achievements
- **Enhanced HUD**: Combo counter, power-up indicators, damage numbers
- **Better AI**: Adaptive difficulty responding to player playstyle
- **Haptic Feedback**: Vibration support for controllers
- **New Effects**: Screen shake, force particles, impact feedback
- **Improved Physics**: Realistic collision detection and knockback
- **Keyboard Support**: WASD movement, Space/Enter for actions
- **Better Mobile Support**: Optimized touch controls and performance

### Changed
- Improved collision detection algorithm
- Enhanced visual effects and animations
- Better UI/UX with accessibility improvements
- Optimized rendering pipeline for better performance
- Updated README with comprehensive documentation

### Fixed
- Frame stuttering on lower-end devices
- Mobile control responsiveness issues
- AI pathfinding edge cases

## [1.0.0] - 2026-04-15

### Added
- Initial release
- 1v1 Duel mode with AI opponent
- 3 difficulty levels (Padawan, Jedi Knight, Sith Master)
- P2P Multiplayer support (PeerJS)
- Basic 3D graphics with Three.js
- Health and blocking mechanics
- Touch and mouse controls
- Beautiful gradient UI with animations
